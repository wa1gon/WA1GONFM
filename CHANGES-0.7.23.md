# filepilot v0.7.23

- Open With lists desktop applications registered with Linux MIME associations.
- Associated applications appear first; other installed applications are available.
- Identifies the default application and offers an optional **Always use** setting.
- Launches selected desktop applications using `gtk-launch`, which honors desktop entry arguments.
- Keeps manual executable entry and Use Default options.
- Updates assembly version to 0.7.23.
