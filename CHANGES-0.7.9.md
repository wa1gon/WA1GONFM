# FM v0.7.9

- Drag files and folders between tabs, file lists, directory tree folders, and separate FM windows.
- Drag files between FM and Nemo using native file data plus Linux URI formats.
- Ctrl+drag copies, Shift+drag moves. Default moves within the same mount and copies between mounts.
- Folder row drop targets, with safeguards against dropping a directory into itself or a descendant.
- Tab hover activates the destination tab after 450 ms.
- Preserves the single-click setting and the v0.7.7 clipboard serialization fix.

Note: Requires compilation and desktop interoperability testing in Rider; not tested here.
